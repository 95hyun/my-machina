# 루브릭 — 탈락 컷·근거용 (순위 결정용 아님)

## 하드 필터 (하나라도 해당하면 탈락, 사유 한 줄)
- 개발 2명이 ~3h 안에 핵심 데모 장면을 실제로 돌릴 수 없다
- 없는 데이터·파트너·하드웨어가 있어야 데모가 된다
- 규제·라이선스 없이는 핵심 기능이 불법이거나 위험하다(의료 진단, 송금 실행 등)
- 계산·정확도가 생명인 도메인(주식·암호화폐 시세 예측 등)
- 핵심 장면이 이미 유명한 서비스·제품과 정면으로 겹친다(주제가 아니라 아이디어 단위로 적용, 겹치는 제품명을 사유에 적는다)

## 채점 (각 1~5, 근거 한 줄)
| 기준 | 5점의 모습 |
|---|---|
| 돈 되는 문제 | 누가·왜·얼마(USD)를 내는지 한 문장으로 말할 수 있고, 지금도 돈/시간을 쓰고 있다 |
| 데모 임팩트 | 3분 안에 "와" 하는 장면 1개가 분명하다(전후 비교가 눈에 보인다) |
| 시간 내 규모 | 핵심 장면이 LLM API + 웹앱 수준으로 구현된다 |
| 블루오션 | 같은 페르소나·국가 조합의 직접 경쟁자가 약하거나, 명확한 차별점이 있다 |
| 주제 적합 | 그 VC 주제 문장에 정면으로 답한다 |
| 팀 적합 | 팀 배경지식·직접 겪은 고통과 이어진다 |
| 인류애적 가치 | 누군가의 기회·존엄·안전을 실제로 바꾼다 |

가중치(기본): 돈 3 · 데모 3 · 규모 2 · 블루오션 2 · 주제 2 · 팀 1 · 인류애 1. 입력 카드에 공지된 심사 기준이 있으면 그것으로 대체한다.
