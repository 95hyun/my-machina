# /mvp — MVP 범위·역할 분담

먼저 `hackathon/RULES.md`를 Read한다(해커톤 공통 규칙 — 이 세션에서 이미 읽었으면 생략).

전제: **모든 작업(코드·시드 데이터·가짜 문서·덱)은 각자의 Claude 세션이 한다.** 사람은 지시·검증·결정만. 생성량은 리스크가 아니다 — 리스크는 데모 경로가 끊기는 것과 세션끼리 서로 막는 것이다.

## 0. 준비
- `hackathon/runs/CURRENT`를 Read → `$RUN`. `$RUN/03-final.md`는 항상 읽는다(확정 원페이저 경로). `$RUN/04-mvp.md`가 이미 있으면 `04-review.md`가 없을 때 2단계, 있으면 3단계로 바로. 처음이면 03-final과 거기 적힌 원페이저, `$RUN/03-redteam.md`의 해당 후보 부분, `$RUN/input-card.md`(개발 스택·시간)만 Read. 03-final이 없으면 `/deepen`부터.
- 개발 스택이 입력 카드에도 인자에도 없으면 `가정`으로 정하고 04-mvp.md 맨 위에 적는다.
- `./hackathon/bin/mark mvp start`.

## 1. `$RUN/04-mvp.md` 작성
### 데모 스크립트 (3분, 먼저 쓴다)
| 시간 | 화면 | 발표자 말 | 보여주는 것 | 백업 |
|---|---|---|---|---|
- 0:00~0:30 훅(페르소나의 고통 장면, 출처 있는 숫자 1개) → 와우 장면은 1:30 전에 → 마지막 30초 사업성 한 줄(`가정` 수치는 가정이라고 말한다).
- **이기는 틈을 화면으로 증명**하는 장면을 넣는다(말로만 하는 차별점 금지).
- **백업은 와우를 보존해야 한다**: 라이브 LLM이 느리거나 실패해도 같은 화면 경로로 미리 만든 결과를 흘려 핵심 장면이 그대로 재생되게(예: "백업 버튼"이 같은 API로 저장된 결과를 넣는다).
- 날짜·시간 의존 값(남은 일수 등)은 `DEMO_TODAY` 같은 상수로 고정.

### 기능
- **Must**: 데모 장면을 만들기 위해 없으면 안 되는 것만. 각 기능 → 어느 장면에 쓰이는지. 피치가 주장하는 지표가 있으면 화면에 보이게 Must로.
- **Cut**: 데모에 안 보이는 것(로그인, 결제, 설정, 다국어 전체 등). 이유 한 줄.
- **가짜로 때울 것**: 하드코딩·시드 데이터로 충분한 것.

### 기술 스파이크 (개발 시작 30분 안에, 판정 기준 포함)
1. **배포·기기 간 접속**: 데모 기기(폰↔노트북 등)가 실제로 같은 서버 상태를 보는가. 서버리스(Vercel 함수 등)는 인스턴스 간 메모리를 공유하지 않으므로 공유 상태가 필요하면 로컬 서버+터널 또는 외부 저장소로 고정.
2. **라이브 LLM 지연**: 와우 장면에 걸리는 호출이 몇 초인가. 직렬 호출이 길면 먼저 응답하고 나머지는 비동기로.
3. 그 밖에 가장 불확실한 외부 의존 1개(API 승인·언어 지원·라이선스).

### 작업 분배 (Claude 세션 단위)
| 사람·세션 | 맡는 범위(파일·디렉토리 경계) | 완료 기준(데모 장면 기준) | 의존 | 사람 검증 시점 |
|---|---|---|---|---|
- 개발1·개발2 세션이 같은 파일을 고치지 않게 경계를 긋고, 둘이 맞출 **인터페이스(API·데이터 형태, 필드 전부)**를 먼저 명시.
- PM 세션: 시드 데이터·가짜 문서·정답 JSON·덱·피치. 개발이 T+15분에 시드를 받도록.
- 체크포인트: T+30분(스파이크 판정), T+1h(뼈대), T+2h(데모 경로 끝까지 연결), 마감 -40분 기능 동결, 마감 -20분 3분 전체 녹화(백업).
- **토큰 예산**: 1인 $500 기준으로 세션별 모델 권장(개발 구현은 sonnet 기본, 막힐 때만 opus 등)을 한 줄.

### 핸드오프 블록
사람·세션별로 자기 Claude 세션 첫 메시지에 그대로 붙여넣을 블록 1개씩(개발자는 이 워크스페이스 루트에 작업 repo를 만들고, 루트에서 연 세션에 블록을 붙여 `/ready`로 시작한다):
```
[해커톤 MVP] <담당 범위 한 줄>
- 만들 것: …
- 경계: 이 파일·디렉토리만 수정
- 인터페이스: …
- 완료 기준: 데모 장면 <n>이 <입력>→<결과>로 돈다
- 하지 말 것: Cut 목록
```
